# Notice on the test data

`tests/annex_e_data.py` holds the input numbers and the printed results of the
worked examples in ISO 13528:2022, Annex E, so that the test suite can show
agreement with the standard. ISO 13528 is a copyrighted publication of ISO.
No text, table layout or figure of the standard is reproduced here, only the
numerical values needed for verification, each with the table it comes from.

The maintainers decided on 2026-10-04 to distribute these values with
attribution. This repository does not
contain the standard and is not a substitute for it.

Example E.4 uses data of the IMEP-111 study (European Commission, Joint
Research Centre); example E.6 uses data provided to ISO by Istituto
Zooprofilattico Sperimentale delle Venezie.
